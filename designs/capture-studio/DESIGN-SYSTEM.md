# 截图模块 · 设计规则（沿用现有语言）

这一版是**在现有界面上做改进**，不是换一套世界观。所有 token 取自 `src/assets/theme.css`，
画板里的颜色、字体、圆角、边框都必须能在代码里对应上。

上一版（暗房/胶片/琥珀/相纸）已废弃：它换掉了整个视觉语言，和 Jedi 无关。

## 这版修掉的实际问题

1. **主按钮对比度不够**：`#fff` on `#3574f0` = **4.28:1**，低于 AA 的 4.5。
   填充按钮底色改为 `#2f68e0`（**5.03:1**）；只用强调色的**文字**（链接、选中胶囊）用 `#2b5fc4`（5.94:1）。
2. **危险色略低于 AA**：`#db3b4b` on white = 4.43:1，文字场景改用 `#c9323f`（5.23:1）。
3. **删除只能悬停**：卡片删除按钮在 hover / focus-within 出现，另有多选 + `Del`，预览页也有入口。
4. **没有多选**：截图只增不减会越用越乱。新增「选择」模式：卡片打勾 → 底部深色操作条（已选 N 项 / 删除 / 取消）。

对比度实测：

```
#27282e on #ffffff 14.69:1      #6c707e on #ffffff  4.93:1
#6c707e on #f7f8fa  4.64:1      #1e5cc4 on #e8f0fe  5.42:1
#ffffff on #2f68e0  5.03:1      #c9323f on #ffffff  5.23:1
#ffffff on #0f1218 18.75:1      #9cc2ff on #0f1218 10.33:1
```

## 各画板要点

**截图库（浅色）**：4 列网格（原来是 3 列大卡，1280 宽下右侧留白过多）；
工具条加类型筛选（全部/图片/长图/视频）与「选择」；新截图给蓝色「刚刚取景」顶标；
卡片悬停浮出删除；选中卡加蓝色描边与勾选；底部多选操作条。

**框选（深色玻璃条）**：沿用 `rgba(15,18,24,.94)` + 13px 圆角；按钮分组（复制/保存 ‖ 识别文字/截长图/录视频 ‖ 发送到 AI）；
命中区抬到 30–32px 高；`截长图` 用蓝色描边表示本次操作；新增像素放大镜（8× + 取色）与键位提示行。

**长截图（滚动中）**：框不再藏起来——浅色画面上保留蓝色虚线取景框 + 四角括号，
右上角「滚动中 · 已捕获 3 屏」，右侧挂已捕获帧的缩略片，底部同款玻璃条（捕获一屏 / 完成 / 取消 + 拼接进度）。

## 第二行：三件「更有意思」的事

语言完全不变（白底、`#3574f0`、等宽数字）。新鲜感来自**交互**，不是来自换皮。

### 1. 贴图（`Pin.dc.html`）
框选后按 `P`，或右键任意截图 →「贴住屏幕」：这张图变成一个置顶的小窗，可拖动、滚轮缩放、
调不透明度，`Esc` 取消。写代码时把接口文档/设计稿贴在编辑器旁边——这是 snipaste 级别的能力，
也是这个模块从「截图存档」变成「随手可用的参考物」的分界线。

实现：新建一个 `decorations:false + always_on_top + transparent` 的 Tauri 窗口（复用现有
`WebviewWindowBuilder` 套路），窗口内只放 `<img>` + 一个悬停工具条；粘贴板/文件路径复用现有命令。
工作量：2–3 天（窗口拖动、缩放、透明度、快捷键）。

### 2. 空格快速预览（`Quicklook.dc.html`）
在库里按 **空格** 直接全屏看大图，`←/→` 切上一张下一张，`Esc` 回列表——不弹对话框、不打断手感。
右侧直接给这块的**识别文字**（OCR 已有，本地离线），下面一条「搜索会同时匹配文件名与识别文字」。
左侧时间轴可拖动跳日期，底部胶片条显示上下文。

实现：gallery 加一个 `quicklook` 状态 + keydown 处理；OCR 结果复用现有 `ocr` 命令；无需新依赖。
工作量：约 1 天。

### 3. 捕捉反馈：闪白 → 显影 → 落位（`Feedback.dc.html`）
按一次 F1，界面做三件事，总共 900ms：
- `0ms` 整屏 8% 白闪（120ms 淡出）——只说"按到了"
- `+180ms` 新卡片从 `blur(1.2px)/84%` 显影到清晰，一条蓝色扫描线扫过 320ms
- `+900ms` 卡片带「刚刚取景」顶标停 5 分钟，底部一条深色提示把下一步（贴住屏幕）递到手边

`prefers-reduced-motion` 下跳过前两帧，只留提示条。
实现：纯 CSS `@keyframes` + 一个 toast 组件。工作量：半天。

### 还想要的话（未画）
**OCR 全文搜索**：搜索框同时匹配文件名与识别文字，结果卡片下方直接给命中片段。
这是把截图库变成「记忆外挂」的那一步，代价是首次全量 OCR + 结果缓存（约 2 天）。

## 与现有代码的对应

- 画板里的颜色都能在 `theme.css` 找到变量；新增的两个值（按钮蓝、危险红）建议进 `--accent-solid` / `--danger-text`
- 组件仍用 Vuetify（`v-dialog` / `v-btn` / `v-slider`），不要引入新的 UI 库
- 网格 `repeat(4, minmax(0,1fr))` 在 <1080px 时降为 3 列、<820px 降为 2 列
