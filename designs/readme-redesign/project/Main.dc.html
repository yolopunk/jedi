核心功能

AI 对话 · 技能系统

会说话的工作台，对话即操作

  • 内置 Agent：让 AI 直接改 Hosts、跑验证脚本
  • OpenAI 等多服务商自由接入，随会话切换
  • 工具调用 + MCP 服务器扩展能力
  • 技能 = SKILL.md 指令包，/命令一键复用
  • 长期记忆，跨会话记住你的偏好
HOSTS 管理

环境切换，一键完成

  • 按项目/环境分组，一键切换生效
  • 条目级开关 + 全局总开关，精细可控
  • 远程订阅：分组绑定数据源 URL，域名清单自动同步
  • 点击域名直达浏览器，省去复制粘贴
知识壁纸

把技术图谱贴上桌面

  • 精选技术知识卡片：架构、网络、数据库…
  • 分类与标签筛选，想看什么一搜即得
  • 预览详情，一键设为桌面壁纸
  • 图文内容支持深入阅读
小宇宙播客

把小宇宙装进桌面

  • 订阅管理：添加、刷新、退订一步到位
  • 导入 OPML，播客库无缝迁移
  • 播放最新节目，进度快速定位续播
  • Show Notes 完整展示，链接一键跳转
截图工作坊

取景、长截图、归档一条龙

  • 全局快捷键（默认 F1）随时唤起
  • 框选取景，所见即所得
  • 滚动截长图，整页内容一图收纳
  • 截图库按日期归档，支持删除与缩略图调节
