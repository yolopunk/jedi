# Jedi 项目 AI Chat 模块需求调研报告

## 一、调研概述

### 1.1 项目背景
Jedi 是一个基于 Tauri v2 + Vue 3 + Vuetify 的跨平台桌面开发者工具箱，现有功能包括：
- Hosts 管理
- 知识壁纸
- 小宇宙播客

技术栈：
- 前端：Vue 3 + TypeScript + Vuetify 3 + Vite
- 后端：Rust + Tauri v2
- 包管理器：pnpm

### 1.2 调研目标
为 Jedi 项目添加 AI Chat 模块做需求调研，包括：
- 模型提供商支持
- MCP (Model Context Protocol) 支持
- Skills 技能系统
- 功能需求与架构设计
