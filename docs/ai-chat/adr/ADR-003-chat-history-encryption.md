# ADR-003: 会话历史加密方案

**日期**：2026-03-05  
**状态**：已批准  
**架构师**：架构师智能体

## 上下文

聊天会话历史可能包含：
- 敏感代码片段
- API Key 和凭证
- 个人信息
- 商业机密

如果本地存储文件泄露，可能导致严重的安全问题。

## 决策

使用用户密码派生的密钥加密会话历史，使用 AES-256-GCM 算法。

## 备选方案

### 方案 1：不加密（否决）
- **优点**：实现简单，性能好
- **缺点**：安全风险高，不符合隐私保护要求

### 方案 2：使用系统密钥链加密密钥（备选）
- **优点**：用户不需要记住密码
- **缺点**：备份迁移复杂，多设备同步困难

### 方案 3：用户密码派生密钥（选中）
- **优点**：用户完全控制，备份简单，可多设备同步
- **缺点**：用户需要记住密码，密码丢失无法恢复

## 理由

1. **用户控制**：用户完全掌控数据，不依赖系统服务
2. **可移植性**：加密数据可以方便备份和多设备同步
3. **算法安全**：AES-256-GCM 是 NIST 推荐的认证加密算法
4. **密钥派生**：Argon2 是目前推荐的密码哈希算法

## 后果

### 正面
- 高安全性（认证加密保证完整性）
- 用户完全控制
- 良好的可移植性

### 负面
- 用户需要记住密码
- 密码丢失 = 数据丢失
- 需要安全的密码输入 UI
- 需要处理密码变更场景

## 实现细节

### 加密算法
- **加密算法**：AES-256-GCM
- **密钥派生**：Argon2id
- **Nonce**：12 字节（随机）
- **Salt**：16 字节（随机，存储在单独文件）

### 依赖
- `aes-gcm` crate：加密算法
- `argon2` crate：密码哈希
- `zeroize` crate：内存安全
- `base64` crate：编码

