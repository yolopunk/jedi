# AiChat 输入框交互改版设计方案

## 概述

参考两张参考图（极简扁平 + Glassmorphism）对 AiChat 页面的输入框进行交互改版，保留全息终端深色主题。

---

## 1. 设计目标

- 输入框在不同会话状态下有差异化视觉行为
- 借鉴参考图的：大圆角、悬浮感、一行工具栏布局
- 保留全息主题的配色和科幻氛围

---

## 2. 输入框状态

### 状态 A：新会话（欢迎状态）

触发条件：`messages.length === 0`

**视觉行为**：
- 输入框**上移居中**（视觉重心在输入框，而非空白消息区）
- 大圆角输入框（24px）
- 背景：浅色半透明（参考图 1 风格）
- placeholder：`Type / for skills`
- 工具栏：居中显示 `/` 命令按钮和 `+` 附件按钮
- 整体氛围：等待式、引导式

### 状态 B：聊天进行中

触发条件：`messages.length > 0`

**视觉行为**：
- 输入框**回到底部固定行**
- 参考图 2 Glassmorphism 效果：
  - 磨砂玻璃背景（`backdrop-filter: blur`）
  - 高光细边框
  - 圆形工具栏按钮
- 紧凑一行布局
- 发送按钮采用亮蓝色作为视觉锚点

---

## 3. 视觉规范

### 输入框容器

| 属性 | 值 |
|------|-----|
| 圆角 | 24px |
| 背景 | `rgba(255, 255, 255, 0.08)` + `backdrop-filter: blur(16px)` |
| 边框 | `1px solid rgba(255, 255, 255, 0.12)` |
| 阴影 | `0 8px 32px rgba(0, 0, 0, 0.3)` |
| 内边距 | 12px 16px |

### 底部工具栏（状态 B）

- **左侧**：`+` 附件按钮（圆形，浅灰背景）
- **右侧**：Model 文字下拉 + 发送按钮（亮蓝色背景 + 白色图标）
- 工具栏按钮尺寸：36px 圆形

### 发送按钮

| 属性 | 值 |
|------|-----|
| 背景 | `#3b82f6`（亮蓝） |
| 图标 | 白色纸飞机 ↑ |
| 圆角 | 50%（圆形） |
| hover | 放大 1.05 + 阴影加深 |

### Model 文字下拉

- 样式：文字 `Sonnet 4.6` + 向下箭头 `v`
- hover：文字微微发光

### Placeholder

- 文字：`Type / for skills`
- 颜色：`rgba(255, 255, 255, 0.35)`

---

## 4. 状态切换动画

- 状态切换使用 `transition: all 0.3s ease`
- 输入框从"居中"到"底部固定"：平滑过渡
- 不使用突兀的开关切换

---

## 5. 实现范围

**涉及文件**：
- `src/views/AiChat/index.vue` — 输入框模板和状态逻辑
- `src/views/AiChat/chat.css` — 输入框样式（含 `.input-console` 区域）

**改动点**：
1. 输入框容器的 CSS 样式（背景、圆角、边框、阴影）
2. 底部工具栏布局调整（一行扁平化）
3. Model selector 改为文字下拉样式
4. 发送按钮改为圆形亮蓝色
5. 会话状态判断逻辑（`messages.length === 0`）
6. 状态 A 下输入框上移居中的布局

---
