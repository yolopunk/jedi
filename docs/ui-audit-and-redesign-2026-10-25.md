# Jedi 全应用 UI 审查与改造方案

- 整理日期：2026-10-25（Asia/Shanghai）
- 当前代码基线：`3536ecb`，分支 `main`。
- 实机视觉审查基线：`37ba7b9` 的 Windows/Tauri 开发版，约 1200 × 768 窗口，中文、浅色为主；聊天页在此前同一轮工作中检查过英文和深色。
- 续审差异：当前基线新增 `EngineSelector.vue` 与引擎相关聊天逻辑，已补充代码审查；未把旧界面的视觉结论套用于新增控件。
- 范围：六个主页面、截图覆盖层、主要弹框、公共导航/状态栏、菜单、反馈与启动页。
- 本轮产出仅为审查文档，不包含界面修复。优先级和设计尺寸是建议，不代表已实施。

## 1. 结论与改造顺序

当前的问题不是缺少更多特效，而是三个层面同时存在：

1. **功能可靠性不足**：设置面板空白、工具执行确认的 Enter 行为与按钮含义冲突、部分设置按钮无实现。
2. **交互规则不一致**：自绘弹框与 Vuetify 弹框的关闭/焦点行为不同；鼠标可用的卡片和菜单缺少等价键盘路径；状态与权限操作混在一起。
3. **视觉体系分裂**：聊天页与截图页已向常规桌面工作区靠拢，技能、壁纸、播客仍是终端标题、等宽小字和符号图标。全局覆盖 CSS 只统一了表面，未统一页面内部结构。

建议顺序：**恢复可用性 → 统一交互与公共组件 → 分页调整信息结构 → 完成真实窗口验收**。不建议一次重写全部页面，也不建议继续用全局 `!important` 叠加“高级感”。

保留：现有导航顺序、启动页黑洞品牌效果、截图原图与美化副本分离、聊天输入区独立占位、侧栏拖拽指针捕获、已有明暗主题令牌。

## 2. 证据等级与覆盖范围

- **V（实机）**：亲自在应用窗口观察到的状态；只代表列出的窗口、数据与主题。
- **C（代码）**：从模板、事件与样式直接确认；不等同于完整操作复现。
- **R（待复测）**：缺少对应数据、环境或本轮未触发的状态，作为验收计划，不作为已发生故障。
- **D（设计判断）**：视觉与信息层级建议，不宣称为客观功能错误。

未在审查中修改 Hosts、执行工具批准、删除订阅、导出截图或安装更新。图像加载初期的旋转指示器、过渡动画中的半透明画面不被当作稳定态缺陷。实机截图已在审查会话中查看，本文件不附带可能包含用户内容的截图；复现入口与源码位置用于后续定位。

## 3. 优先级定义

| 等级 | 含义 | 完成要求 |
|---|---|---|
| P1 | 阻断功能、误操作风险或关键交互错误 | 先于视觉改造修复，并验证行为 |
| P2 | 明显影响理解、一致性、可读性或常用操作效率 | 随对应页面改造完成 |
| P3 | 品质、密度、动效与辅助信息优化 | 在 P1/P2 稳定后处理 |

本轮没有足够证据定义 P0；不将普通视觉偏好升级为严重故障。

## 4. 问题清单与具体改造要求

### 4.1 功能与高风险交互

| ID / 优先级 / 证据 | 问题与定位 | 改造及验收 |
|---|---|---|
| F01 · P1 · V/C | **设置内容空白**。点击标题栏设置，常规与高级页签均只有标题和标签。`SettingsDialog.vue` 使用三个 `*SettingsTab`，script 未导入；`main.ts` 无对应注册，Vite 只配置 Vue/Vuetify 自动导入。 | 显式导入子组件，逐项核对绑定。三个页签必须有内容；反复切换不空白；控制台无组件解析警告。类型检查通过不能替代这项实机验收。 |
| F02 · P1 · C | **确认框 Enter 含义错误**。`ToolConfirmCard.vue` 容器 `handleKeydown` 对任何 Enter 都调用 `resolveConfirmation(true)`，并默认聚焦“批准”。焦点处于“拒绝”时，其键盘激活可能被父级处理改成批准。 | 移除容器级无条件批准；让原生按钮执行自身动作，Esc 拒绝。高风险动作初始焦点放在说明或拒绝。验收：分别聚焦拒绝/批准/始终允许，按 Enter 和 Space，结果严格对应按钮；不触发真实危险命令，用模拟确认请求验证。 |
| F03 · P1 · C | **设置中的假入口与错误平台路径**。`settings/AdvancedSettingsTab.vue` 备份/重置按钮没有事件处理，Hosts 路径硬编码 `/etc/hosts`；在 Windows 上与实际系统路径不符。当前还被 F01 遮住。 | 未实现项隐藏或明确不可用及原因；需要实现时独立任务处理。路径从已有后端能力获取；失败在界面提示。验收：每个可用按钮都有可观察结果，Windows 显示真实路径，取消/失败不呈现成功。 |
| F04 · P1 · C/R | **新增引擎与模型控件可能重叠，菜单样式不完整**。`index.vue` 的输入网格同时放入 `EngineSelector` 和 `.model-selector`；`chat.css` 把 `.model-selector` 固定在第 2 行第 4 列。子组件根节点也带这个类，会匹配父级 scoped 规则。子组件内部的 `model-dropdown-*` 则不会自动继承父级 scoped 样式。 | 给引擎和模型明确不同的网格位置；将需要共享的触发器/菜单样式放在实际拥有该 DOM 的组件或有限共享样式中。验收：内置/外部引擎、长名称、窄窗口均不重叠；菜单定位、背景、滚动与层级完整。此项为当前新代码审查结论，仍需实机复现确认具体外观。 |
| F05 · P1 · C | **自绘 MCP 弹框缺少完整模态行为**。`McpServersDialog.vue` 使用普通 div 遮罩；未见 dialog 语义、焦点进入/循环/恢复和 Esc 处理。已有 `SkillsManagerDialog.vue` 实现了焦点控制，可参考。 | 统一使用已有弹框能力或局部补齐焦点行为；命令/参数输入添加持久标签，关闭表单前保护未保存内容。验收：Tab 不进入背景，Esc 策略明确，关闭后焦点回触发器；屏幕阅读器能读出标题及字段名称。 |

### 4.2 全局外壳与视觉体系

| ID / 优先级 / 证据 | 问题与定位 | 改造及验收 |
|---|---|---|
| G01 · P2 · V/C/D | **页面标题没有共同层级**：对话是 60px 工具栏；技能是 `[SKILLS]`；壁纸/播客是英文 ARCHIVE；截图有大标题、介绍、集合栏及日期栏。 | 固定页面标题/主操作/筛选的职责。画廊允许图片优先的例外，但减少重复标题。六个页面来回切换，标题起点、主要操作位置与正文边距有一致规律。 |
| G02 · P2 · V/C | **字体混用**：壁纸和播客大面积使用 JetBrains Mono；技能将内部标识大写加粗，说明是英文长段；同页中文、英文、代码呈不同密度。 | UI 正文使用 `--jedi-font-ui`；等宽仅用于 IP、路径、代码、日志。正文建议 13–14px，辅助信息 12px；10–11px 只用于不影响决策的次要数据。中英文分别检视换行与截断。 |
| G03 · P2 · V/C | **图标来源与可访问名称不一致**：SVG/mdi 与 `◀`、`↻`、`✕`、emoji 混用；标题栏的多个图标按钮在可访问树中没有名称。 | 复用现有 mdi SVG；图标按钮有独立 aria-label，不能仅依赖悬浮提示。检查标题栏、预览关闭、刷新、播放、章节、后台任务等入口。 |
| G04 · P2 · C/D | **公共 CSS 与局部样式相互覆盖**。`theme.css`、`console-dialog.css`、`desktop-ui.css` 和各页重复声明卡片、输入、弹框；部分规则使用跨页面类名与 `!important`。 | 按组件逐步迁移，不做全站格式化/重写。公共文件只管令牌和明确共享规则，布局由页面负责。改动一个页面不应改变其他页面按钮尺寸或卡片背景。 |
| G05 · P3 · V/D | **状态栏与品牌区信息密度失衡**：侧栏品牌留白较大，底栏网络/CPU/内存/图标/版本又密集。 | 保留品牌辨识；降低底栏装饰密度，资源指标用悬浮说明或可展开详情表达。主操作不依赖读懂微小指标，125%/150% 缩放下文字不挤压。 |
| G06 · P2 · C/R | **窗口尺寸与缩放尚无完整验收**：主窗最小 980×600，侧栏 176–320px，历史面板还会分走宽度。部分断点按整个视口而非实际内容宽度判断。 | 以实际容器宽度布局；每页明确唯一主滚动区。验收最小窗口、侧栏最大宽度、125%/150% DPI；底部操作和关闭按钮始终可达。未实测前不得宣称响应式通过。 |

### 4.3 对话、模型、任务与权限

| ID / 优先级 / 证据 | 问题与定位 | 改造及验收 |
|---|---|---|
| C01 · P2 · V/C | **中文界面仍出现英文系统文案**：历史时间 `23 HRS AGO`；`ModelSettings.vue` 的 Configure Provider、Loading providers、Retry；后台任务的 Workers/No active workers。 | 自有 UI 文案统一 i18n，用户数据/模型名称不强行翻译。通过 locale 的相对时间格式化；中文页不出现英文占位和原始翻译键。 |

| C04 · P2 · C/R | **任务及调用链路文字过小、状态难扫描**。`AgentTrace.vue` 大量 10–11px 等宽信息；后台任务面板缺少统一关闭命名与状态说明。 | 把任务名/状态/耗时/操作作为第一层，参数、日志折叠为第二层。只对日志使用等宽；错误有简明摘要和展开详情。长任务名、失败信息不得挤掉停止按钮。 |

## 5. 统一设计约定（建议值）

| 项目 | 约定 |
|---|---|
| 页面骨架 | 页面标题与主操作同层；筛选另层；内容只有一个主要滚动区。模态正文可滚动，关闭和主要操作可达。 |
| 色彩 | 中性色承担表面/边框/正文；蓝色只强调主操作/当前选择；绿色表示明确成功状态；危险色只用于确有风险的动作。不能只靠颜色区分状态。 |
| 字体 | 页面标题 18–22px，内容型画廊可适当更大；正文 13–14px；辅助文字 12px。代码、路径、IP 才使用等宽。 |
| 间距与尺寸 | 4/8px 基础节奏；页面内边距建议 20–24px；工具按钮 32–36px；常规输入 36–40px。密集表格也要保留完整命中区。 |
| 圆角与阴影 | 复用当前令牌：控件约 8px，面板约 14px，弹框约 20px；阴影区分浮层，不给每一层容器加阴影。 |
| 弹框 | 标题说明对象与任务；正文清晰标签；底部明确取消/主操作。普通 Esc 关闭，脏表单退出保护；高风险弹框不默认批准。 |
| 动效 | 悬停约 120–160ms，菜单/弹框约 180–220ms；仅 opacity/transform。侧栏拖拽不做宽度插值动画；尊重减少动态效果。 |
| 状态 | 区分首次空态、筛选空态、加载、失败、离线、权限不足、成功；不能只靠 toast 替代页面失败内容。 |
| 可访问性 | 原生按钮优先；所有图标操作有名称；Tab 顺序与阅读顺序一致；焦点可见但不形成整屏装饰框。对比度需按最终颜色实测，不能从截图主观宣布达标。 |

## 14. 截图 OCR 实施记录（2026-10-25）

- 框选工具栏新增“识别文字”；选区仍保存到系统图片目录的 `jedi` 画廊，主窗口随后打开对应预览并自动识别。
