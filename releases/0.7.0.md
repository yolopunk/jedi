# Jedi v0.7.0

## 安装界面全面重设计

- 全新白底极简竖版安装器（440×600），与品牌设计稿一致
- 标题栏与卡片一体化浅色设计，窗口顶部悬停显示标题与系统控制键
- 真实鼠标点击修复：安装/取消按钮改用原生控件，点击 100% 响应
- 分组「编辑数据源 URL」铅笔入口，路径超长自动截尾
- 安装完成页新增「启动 Jedi 工具箱」直达按钮

## 品牌图标焕新

- 应用/任务栏/托盘/安装器统一为白底 App 图标（白色圆角方块 + Koala）
- 图标跟随应用主题自动切换：深色主题深底白标，浅色主题白底黑标

## 功能修复

- Hosts 管理：修复生产版本中「编辑数据源 URL」弹框无法弹出的问题
- 安装包支持静默安装（/S）与被动模式（/P），逻辑与 GUI 一致

## 安装器 QA 基建

- 新增安装器渲染预览器与截图流水线（含安全审计），无需真实安装即可验证 UI
