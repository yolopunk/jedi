# Jedi v0.10.0

截图支持直接标注与快捷输出，补齐常用桌面截图流程。

## 新增

- **窗口与区域取景**：指针悬停自动高亮窗口，单击选择窗口，拖动自由框选；支持八向调整选区、方向键逐像素微调和全屏选择。
- **截图内标注**：矩形、椭圆、箭头、直线、画笔、马赛克、文字，支持颜色、线宽、字号、撤销和重做。
- **快捷输出**：Enter 或双击选区复制，Ctrl/⌘+S 打开 PNG 另存对话框；取消另存后保留选区与标注。
- **像素辅助**：放大镜显示坐标与颜色，未确认选区时可用 Ctrl/⌘+C 复制颜色值。
- 标注结果可直接用于复制、保存、OCR、贴图和发送 AI；已有标注时禁用实时长截图与录屏，撤销标注后可继续使用。

## 修复与改进

- 按冻结帧原始像素计算选区与导出尺寸，修正高 DPI 下的坐标映射，并调整原生悬浮工具条的位置换算。
- Windows 自动选窗包含无标题应用窗口，并排除最小化、隐藏和桌面浮层等不适合的窗口。
- 修复贴边文字预览与输出不一致、文字输入框右键误清空选区、未结束笔画时提前输出等问题。
- 重复截图快捷键保留当前编辑；保存及实时捕获初始化期间保护会话，避免另一屏取消造成数据丢失。
- 冻结帧采用单文件临时生命周期管理，捕获中途失败与会话结束后清理临时文件。

## 验证与限制

- 已通过前端类型检查与生产构建、Windows 后端编译、28 项截图相关测试，以及浏览器交互和导出 PNG 像素检查。
- 真实系统剪贴板、原生保存对话框、混合 DPI 多屏和 macOS/Linux 桌面交互仍需实机验证。
- 保留默认 F1 及自定义截图快捷键、长截图、录屏、OCR、贴图和 AI 入口；录屏音频等既有限制保持不变。
