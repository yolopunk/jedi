## Agent 对话与模型

- 修复 Codex 初始化失败、请求超时和部分回复事件处理，避免持续等待或丢失回复。
- 修复 Claude Code、OpenCode、Antigravity 的错误处理，调整 Cursor CLI 的输出参数与结果解析。

- 不支持的 Agent 会明确报错，避免静默切换到内置引擎；仅支持检测的 Agent 仍不可选。

## Windows 启动修复

- 修复 OpenCode 等 npm 安装的 Agent 被误用 Unix 启动脚本、提示 program not found 的问题。
- 正确选择 Windows .exe、.cmd 或 .bat 启动器，并兼容旧的无扩展名检测记录。
- 解析 fnm 临时路径到实际安装位置，并修复启动脚本路径含空格时的引号处理。
