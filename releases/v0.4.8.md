## Agent 状态与对话反馈

- 引擎列表展示就绪、待登录、路径无效等检测状态，优先选择已就绪的 Agent。
- 区分配置中的默认模型和 Agent 本轮实际报告的模型；无法确认时明确提示。
- 对话展示运行阶段与耗时，并在长时间无响应时自动结束本轮。
- 登录、模型、网络、额度和进程异常等错误提供分类提示与可展开详情；发送失败后恢复输入内容。

## Agent 对话稳定性修复

- 按 Agent 和 Windows / WSL 宿主隔离原生会话 ID，避免切换引擎后误用其他 Agent 的会话。
- 已输出部分内容后发生错误，仍正确标记失败并保留已生成文字。
- 修复停止生成后被错误记录为已完成的问题。
- 修复驱动回放脚本，并增加会话隔离、停止和失败状态持久化回归检查。

## 验证范围

- 前端生产构建与三组自动回放检查通过。
- 自动回放使用模拟进程事件；真实 Agent 的应用内走查仍待补充，尤其是 Codex app-server 链路。
