## 截图标注编辑

- 截图库「图片编辑」模式新增标注工具栏：文字、直线、箭头、矩形与画笔自由绘制，附六色色板和线宽调节。
- 点击画布放置文字，Enter 提交；再次点击可重新编辑。浅色文字配深色描边、深色文字配白色描边，任意截图内容上都保持可读；文字工具有独立字号滑杆。
- 选择工具可拖动已有标注，选中项显示虚线框，Delete 键删除；支持撤销（Ctrl+Z，最多 60 步）与一键清空全部标注。
- 标注保存在图片坐标系中，调整留白、圆角、阴影不会导致标注漂移；导出时与背景画框一起写入副本，原图始终保留。
- 编辑内容（含标注）写入会话草稿，切换到预览再返回不丢失。
- 修复点击画布后文字输入框被焦点变化立即关闭的问题。

## 弹窗按钮样式统一

- 关于、帮助、更新弹窗，Hosts 分组 / 新增 / 删除 / 编辑弹窗，以及模型设置页的操作按钮统一为 console-btn 风格；v-btn 仅保留给图标按钮。
- 加载态改为文案互换加禁用，不再使用转圈指示器。

## 验证范围

- vue-tsc 类型检查与 Biome 检查通过。
- 无头浏览器端到端走查通过：绘制矩形 / 箭头 / 直线 / 画笔、文字输入与再编辑回显、拖动选中、撤销回退、保存导出全流程，全程无控制台异常。
