## Hosts 远程数据源

- 分组可绑定一个返回 Jedi JSON 分组格式的 URL：添加分组时选择「远程 URL」即可；进入 Hosts 页后在后台自动同步，不阻塞页面加载。
- 数据源持久化到 `hosts_sources.json`（按分组名 upsert）；分组重命名时订阅自动跟随，删除分组时订阅一并解除，不会在下次同步时被重新拉回来。
- 合并策略：以远端为准覆盖域名列表，但保留本地同名条目的启用/禁用状态；远端返回空列表时清空分组并保留订阅（远端恢复后自动重建）；数据无变化时跳过 hosts 写入。
- 修复 `fetch_remote_config` 未注册为 Tauri 命令的问题——此前用远程 URL 创建分组必然失败。
- 分组支持编辑订阅地址：新 URL 只有在同步成功后才落盘，失败时保留旧地址。
- 数据源请求增加 20 秒超时、User-Agent 标识与非 2xx 状态报错。

## K8s ingress 适配器

- 新增 `scripts/k8s-hosts-api.yaml`：把集群内全部 ingress 自定义域名转成 Jedi 的分组格式，一条 `kubectl apply` 即可部署。
- 纯 shell 实现（busybox `nc` / `wget` / `awk` / `sed`），不依赖 Python、无需构建镜像；脚本以 ConfigMap 挂载。
- 只读权限：ServiceAccount 仅持有 ingress 的 `get` / `list`；Pod 内直连 K8s API，脱离集群运行时自动退回调用 `kubectl`。
- URL 参数：`ip` 强制统一指向（缺省用 `DEFAULT_IP`）、`name` 返回的分组名、`namespace` 只统计指定命名空间。
- 携带访问日志（标准错误），便于排查调用来源与失败。

## Hosts 写入与数据安全

- hosts 文件读写失败不再静默吞掉：没有管理员权限时会明确报错，而不是界面报成功、文件却没变。
- 读取失败时中止写入，避免把整份 hosts 文件重建成只剩 Jedi 段。
- 新增显式「删除分组」：二次确认并显示该分组的条目数；远程分组会提示订阅一并解除；写入失败时自动回滚界面状态。
- 移除凭空生成的 "System Default" 分组：未配置时展示空状态引导页，不再显示文件里并不存在的条目。
- hosts 解析抽出独立的 `parse_hosts_groups` 并补充单元测试（无 Jedi 段、空段、禁用条目、一行多域名、重复段取最后一段）。

## 列表与分组栏交互

- 移除列表底部「显示更多」按钮，改为纯无限滚动；用 IntersectionObserver 配合视口兜底，修复大窗口 / 数据晚到场景下只显示第一页且无法继续加载的问题。
- 点击条目开关不再把列表位置重置回第一页。
- 分组 tab 内的操作按钮收进右侧工具栏（同步 + 更多菜单），修复 tab 内嵌套按钮的可访问性问题，消除悬停时 tab 宽度跳动，删除操作前加分隔并标记为危险项。
