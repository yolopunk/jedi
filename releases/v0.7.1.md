# Jedi v0.7.1

## 截图页面 · 按钮 hover 修复

- **预览 / 美化切换按钮**：悬停时增加浅色背景反馈——此前只有文字微变色，几乎不可见
- **光标样式**：切换按钮、缩略图重试按钮补充 `cursor: pointer`，此前悬停显示默认箭头，看起来不可点击
- **立即截图主按钮**：悬停时阴影加深并轻微上浮 1px，按下回落——不再依赖 Vuetify 默认 overlay 与自定义阴影的混浊叠加
- **美化编辑器色点**：修复悬停已选中的色点反而缩小的问题（hover scale 与 active scale 冲突）

## 其他

- 修正 v0.7.0 发布说明文件命名（`releases/v0.7.0.md`），确保工作流能读取详细更新内容
