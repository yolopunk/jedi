# Jedi v0.7.2

## 修复：正式安装包里的播放与样式异常

这两个问题的共同原因是 **CSP 只在生产构建中生效**——`pnpm tauri dev` 下页面由 Vite 直接提供、不注入 CSP，所以开发时完全正常，只有装到机器上的包才会犯病。

### 小宇宙点击播放没有声音

- **根因**：CSP 没有声明 `media-src`，`<audio>` 回落到 `default-src 'self'`，跨域的小宇宙音频请求被直接拒绝（`MEDIA_ERR_SRC_NOT_SUPPORTED`）。播放条看起来在播、时间也不动，但一点声音都没有。
- **修复**：新增 `media-src 'self' https: blob: data: asset: http://asset.localhost`
- **增强**：播放改为点击时显式 `play()` 并监听 `error`，失败原因（无音频地址 / 网络错误 / 被自动播放策略拦截）会以提示条告知，不再静默失败；`seek` 在 `duration` 为 `NaN` / `Infinity` 时不再写入非法值

### hover 颜色错乱、按钮变黑、文字消失

- **根因**：Tauri 会往 `style-src` 注入 `nonce-...`，而按 CSP 规范，一旦出现 nonce/hash，`'unsafe-inline'` 即失效。Vuetify 的主题样式表是运行时用 JS 插入 `<style>` 的（不带 nonce），于是整张表被拒：`--v-hover-opacity`、`--v-focus-opacity`、`--v-activated-opacity` 以及 `.bg-*` / `.text-*` 工具类全部缺失。`v-btn` 的 hover 规则 `opacity: calc(var(--v-hover-opacity) * ...)` 因变量缺失而失效，`opacity` 回退为 `1`，遮罩层用 `currentColor` 把按钮整块涂满——按钮变黑、文字同色不可见。
- **修复**：`dangerousDisableAssetCspModification: ["style-src"]`，让 Tauri 不再向 `style-src` 注入 nonce，Vuetify 运行时样式正常加载；`script-src` 的加固保持不变
- **连带修复**：
  - 所有 `color="primary"` 的 Vuetify 组件恢复品牌蓝（此前实际渲染成灰色）
  - hover / focus / active / selected 状态恢复正常
  - Vue `:style` 动态样式恢复生效（播客进度条填充、CPU/内存占用条、缩略图尺寸滑块等此前在正式包里失效）

## 已知问题

- `connect-src 'self' https:` 仍会拦截 Tauri 的 `http://ipc.localhost`，部分插件 IPC 调用会在控制台报 `Refused to connect`，不影响主要功能，计划在后续版本补 `ipc: http://ipc.localhost`
