# Jedi v0.8.0

## 新功能：滚动截长图

长页面（聊天记录、文档、列表）不再需要多次截图手动拼接。

- **入口**：`Ctrl+Alt+S` 冻结屏幕、框选区域后，工具条新增「截长图」按钮（与复制/保存/OCR 并列）
- **流程**：进入滚动模式后屏幕解锁，悬浮控制条提供「捕获一屏 / 完成 / 取消」，快捷键 `Space` = 捕获、`Enter` = 完成、`Esc` = 取消；在目标页面滚动一段，按一次空格，重复到覆盖完整内容
- **智能拼接**：后端对相邻帧做行级哈希精确匹配 + 像素容差校验的两级重叠检测，自动去除重复区域、垂直拼接为单张 PNG，直接进入截图库历史
- **不丢帧**：某一屏找不到可靠重叠（内容平滑渐变、滚动跳变）时降级为首尾直接相接，并弹出来自后端的可见警告提示检查接缝——绝不静默丢内容
- 第一屏直接取自冻结帧，覆盖窗口自身的边框与控件不会混进画面

## 新功能：选区录制视频

- **入口**：框选区域后点击工具条「录视频」，按选区物理尺寸录制 MP4（H.264）
- **纯 Rust 编码**：openh264 编码 + mp4 封装，无 ffmpeg / 系统依赖，三平台开箱即用；按屏幕内容自适应码率（2–12 Mbps），默认 15 fps
- **录制体验**：录制期间选区保留红色边框 + REC 计时徽标，覆盖窗口转为点击穿透并从系统捕获中排除（Windows，`WDA_EXCLUDEFROMCAPTURE`）——边框和徽标不会入画，可以直接操作被录的应用；悬浮控制条随时「停止」
- **上限保护**：单次录制最长 10 分钟，到时自动停止并产出文件；关闭应用时录制线程干净收尾，已录内容照常落盘，不丢不漏
- **画廊集成**：截图库历史条目新增类型区分（图片/视频），视频卡片有专属标识，预览面板可内嵌播放，并提供「打开文件」用系统播放器观看

## 其他

- 截图库历史同时收录 PNG 与 MP4（最近 24 条），新增 `screenshot_open_file` 命令
- 录制/滚动会话期间的全局热键仅在该会话内生效，会话结束即注销，不影响日常快捷键
- 新增依赖：`openh264`、`mp4`、`bytes`（均纯 Rust，Windows/macOS/Linux 均可编译）

## 已知限制

- 滚动模式的全局 `Space`/`Enter` 热键在捕获期间全局生效：此期间在其他应用打字含空格会触发一次捕获，建议专注完成截取（也可全部用悬浮条按钮操作）
- 内容为极平滑渐变（相邻屏几乎无特征行）时可能触发拼接降级，接缝处可能有少量重复或跳变，会有明确警告提示
- 选区录制目前以 Windows 为主验证平台，macOS / Linux 已做条件编译保证可构建，实际录制效果待后续版本验证
