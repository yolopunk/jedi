# Jedi Forge v0.8.2

> 从本版本起，产品更名 **Jedi Forge**（原 Jedi Command / Jedi 工具箱）——Forge（锻造）与 Force（原力）谐音双关。

## 截图模块整体重设计

以「取景棚 Capture Studio」设计稿为准 1:1 重做，六个画板全部落地：印样台截图库、框选取景器、滚动胶片、贴图、空格快速预览、捕捉反馈。

### 截图库

- 类型筛选：全部 / 图片 / 长图 / 视频，带数量角标
- 多选模式 + 批量删除：底部深色操作条（已选数量 / 体积 / 删除 / 取消），`Del` 键直删
- 导入图片：系统文件选择器 → 统一转存 PNG 入库
- 卡片重绘：相框卡纸式缩略图、长图 / 视频角标、删除按钮常驻
- 工具条汇总张数与总体积；缩略图大小滑杆、刷新保留

### 取景器（框选）

- 选区重绘：白描边 + 蓝色外圈，方形手柄
- 尺寸角标居中显示，附带缩放系数（如 `620 × 380 · 1.0×`）
- 像素放大镜：挂在选区右下角，8× 放大 + 实时取色（hex）
- 取景条重排：截长图高亮项、双分隔线、下方快捷键提示行（Enter / Esc / ⇧C / P / 双击）
- 左上角 `取景中 · DISPLAY n` 状态徽标

### 长截图

- NEG 胶片条：取景框右侧实时展示已捕获帧（01 / 02 / 03…）
- 控制条重绘：蓝环帧计数、`SPACE` / `ENTER` / `ESC` 键位芯片、拼接进度段
- 框内滚动提示、画面底部操作指引

### 新功能：贴图（Pin）

- 框选后按 `P`，或快速预览里点「贴住屏幕」，或保存提示条一键贴图
- 置顶无边框悬浮窗：拖动移动、滚轮缩放（20%–400%）、不透明度 20–100%、一键复制、`Esc` 收起

### 新功能：空格快速预览

- 库内悬停按 `Space`（Finder 式开合）
- 顶栏：返回库 / 复制图片 / 贴住屏幕 / 图片编辑 / 删除
- 左侧日期时间轴 + 底部胶片条（`←` `→` 导航，`03 / 11` 计数）
- OCR 右栏逐行卡片化（`L1 / L2 …`），一键复制全部文字

### 捕捉反馈（三帧）

- 快门闪白（120ms）→ 新卡片显影（模糊 → 清晰 + 蓝色扫描线）→ 深色提示条「已存入截图库 · 贴住屏幕」
- 遵循 `prefers-reduced-motion`：直接落终态，不闪白、不显影
