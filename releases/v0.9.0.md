# Jedi Forge v0.9.0

> 截图模块三大功能（贴图 / 截长图 / 录屏）修复可用性缺陷，交互模型对齐 PixPin。

## 修复的可用性缺陷

- **录屏无法再次开始**：录制线程出错或到时自动停止后，内部状态永不清理，之后一直报「已有录制进行中」，重启才能恢复。现在收尾统一走停止命令，状态永不残留，线程结束的僵尸会话也会自动清理
- **录屏出错无感知**：此前任何中途错误会立刻拆光全部界面，错误提示发往正在销毁的窗口，表现为「界面闪一下就没了、无报错、无文件」。现在错误先在悬浮条与取景框上展示 2.5 秒，再自动收尾
- **录屏视频快进失真**：此前按固定帧时长封装、捕获变慢时视频时长被压缩。现在逐帧记录真实时间戳（90k timescale），视频时长与真实录制一致
- **截长图模式吞键盘**：滚动模式期间 `Space` / `Enter` / `Esc` 被注册为全局热键，系统级吞键，其他应用无法输入空格/回车。全局热键已彻底移除（v0.8.1 起的已知限制，本版解决）
- **截长图拼接错乱**：白底页面的纯色空白行会被当作重叠锚点，产生错误重叠导致内容丢失/重复。现在纯色行不再参与锚定，比较时忽略两侧滚动条列
- **贴图无反馈失败**：贴图窗口创建失败被静默吞掉，表现为「按了没效果」。现在失败原因会显示在取景框的错误条上
- **多屏裁错屏**：捕获时按显示器枚举顺序取屏，顺序不稳定时会裁到错误的显示器。改为按显示器物理原点匹配

## 贴图（Pin）：补齐入口与 PixPin 交互

- 取景框工具栏新增「贴住屏幕」按钮（此前只有隐藏的 `P` 键）
- **贴在截取原位**：从选区贴图时窗口落在截图所在位置（PixPin 行为）
- 双击关闭；`Ctrl`+滚轮调节不透明度（每档 5%）；中键单击恢复 100% 原始大小；悬停工具条新增置顶开关
- 贴图平时可被正常截图截到；仅在截长图 / 录屏会话期间临时排除出捕获，会话结束自动还原

## 截长图：随滚动自动捕获 + 实时拼接预览

交互模型从「手动按空格拍一屏」重做为 PixPin 手动滚动模式：

- 进入截长图后**直接滚动页面即可**：画面变化自动捕获（150ms 轮询差分 + 250ms 节流）并增量拼接，不再需要按键拍屏
- 取景框右侧 NEG 预览条实时展示累积长图，徽标显示已拼高度
- **匹配失败可恢复**：滚动过快或选区包含固定元素时提示「未匹配，往回滚一点再继续」，回滚后自动衔接（超出的部分会被重新捕获，不产生重复）
- 拼接算法支持固定吸顶栏（吸顶条带不参与匹配）；悬浮条保留「补拍一屏」手动兜底
- 累积高度上限 30000px，防止超长滚动内存失控；完成时未匹配帧直连拼入并给出警告，绝不静默丢帧

## 录屏：暂停与真实时长

- 新增**暂停 / 继续**（悬浮条按钮），暂停期间不捕获、不计入视频时长
- 默认帧率 15 → **24 fps**（PixPin 默认，5–30 可调）
- 计时与后端起始时刻对表，窗口复用不再漂移；到最长时长（10 分钟）由悬浮条触发统一收尾，线程内仅作兜底停录

## 已知限制

- 录屏暂不含音频（系统声音 / 麦克风）与 GIF 导出，计划后续版本
- 截长图为「手动滚动 + 自动捕获」模式；PixPin 式自动滚动注入（滚轮模拟）未实现
- 贴图的鼠标穿透 / 缩略图模式未实现
- 覆盖窗排除出系统捕获（WDA_EXCLUDEFROMCAPTURE）仅 Windows 生效；macOS / Linux 上截长图与录屏的取景边框可能入镜
